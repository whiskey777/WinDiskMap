## [1.0.0-beta.3] — 2026-11-25

### Добавлено

- В верхней строке TUI теперь выводятся имя программы и версия сборки
  (например, `WinDiskMap 1.0.0-beta.3`). Это же заголовок используется при выводе
  прогресса (`--csv`, `--headless`).
- Строка `<Filtered>` показывает количество, суммарный размер и самые свежие даты
  файлов, скрытых активным фильтром в этой папке.
- В CI добавлены проверки генерируемого PowerShell-скрипта WinRM, строк `<Filtered>`
  и настроек тем/версии в шапке TUI.

### Изменено

- WinRM-режим проверен на реальном удалённом хосте Windows Server 2016: сканирование
  завершается, дерево и CSV строятся. Работает он медленно — это ожидаемое ограничение
  текущего транспорта, а не признак неработоспособности. Статус сборки остаётся beta.
- Документация приведена к фактическому состоянию WinRM: описание потока NDJSON,
  известные ограничения и порядок проверки удалённого хоста обновлены.

### Исправлено

- TUI определяет старый conhost (Windows Server 2016, build 14393) и переключается
  на резервную 16-цветную палитру: папки в `Modern Dark` больше не становятся
  синими, клавиши в подсказках снова отличаются от описаний. Принудительно режим
  включается через `WINDISKMAP_NO_TRUECOLOR=1`.
- TUI больше не падает с `IndexOutOfRangeException` на серверах с аптаймом более
  ~24.86 суток: индекс спиннера теперь вычисляется из беззнакового `TickCount`.
- Упаковка portable-архивов больше не зависит от модуля `Compress-Archive`: используется
  `ZipFile` из .NET, поэтому сборка не блокируется локальной политикой подписи скриптов.
- CodeQL: чтение версии сборки в TUI больше не использует широкий `catch` — предупреждение
  `Generic catch clause` устранено изменением кода, без подавления.
- WinRM: путь агента берётся из `$env:TEMP` удалённого хоста, а не локального;
  устранена ошибка `Cannot find path ... WinDiskMap-agent.exe` при разных
  пользовательских профилях на клиенте и сервере.
- WinRM: чтение NDJSON и очистка идут через отдельную сессию — устранена ошибка
  `The session ... is not available to run commands. The session availability is Busy`,
  когда агент занимал сессию фоновой задачей.
- WinRM: аргументы агента квотируются по правилам CreateProcess (только двойные
  кавычки); одиночные кавычки больше не попадают в путь. Код возврата и stderr
  агента читаются из отдельных файлов, при ошибке показывается их содержимое.
- WinRM: убран `-NoNewWindow` у `Start-Process` — в неинтерактивной сессии он
  вызывал `Access is denied`; диагностика ошибки задачи теперь включает FQID
  и позицию в скрипте.
- WinRM: поток NDJSON читается порциями до 256 КБ и декодируется stateful UTF-8;
  устранены задержки на больших пачках строк и искажение имён на границе чанка.
  После завершения агента файл дочитывается до конца — последние записи больше
  не теряются.

## [1.0.0-beta.2] — 2026-11-24

### Добавлено

- Переключение тем TUI по `t` (также работает физическая клавиша `T` в русской раскладке):
  `Modern Dark` по умолчанию, `Нортон / FAR` и прежняя палитра как запасная.
  Выбор сохраняется в `%APPDATA%\WinDiskMap\theme.txt`; старый идентификатор
  `vscode-dark` из beta.1 продолжает работать.
- Клавиши и стрелки в строке подсказок выделены акцентным RGB-цветом, описания
  приглушены. На узком окне описания отбрасываются целиком, чтобы не обрезались
  последние клавиши (в том числе `q` — выход).

### Изменено

- Все темы TUI переведены на явные RGB-цвета и собственный фон: оформление больше не
  зависит от цветовой схемы Windows Terminal или палитры классического conhost.
  При выходе выполняется жёсткий ANSI-сброс, чтобы терминал вернул свои цвета.
- Название темы стало постоянным блоком в футере; временные сообщения о действиях
  (свёрнута папка, экспорт, удаление и т. п.) выводятся отдельным блоком и больше
  его не затирают.

## [1.0.0-beta.1] — 2026-11-24

### Добавлено

- TUI с живым обновлением дерева, двумя языками (ru/en), мышью SGR и корректным выходом по Ctrl+C.
- CSV-экспорт: UTF-8 BOM, разделитель `,`, `--details`, `--depth`, `--only`, английские заголовки.
- Привилегированный сбор с прямого чтения `$MFT` и портативный обход каталогов через Win32;
  результаты совпадают по 13 основным метрикам.
- Удалённый скан по WinRM с потоком NDJSON и агентом `net48`.
- CI/CD: сборка и smoke test, CodeQL, Dependency Review, Dependabot, release workflow с
  опциональной подписью SignPath.
- Многоразмерная иконка приложения (16–256 px) в ресурсах обоих EXE.

### Изменено

- Единственный источник версии — `<Version>` в `src\WinDiskMap\WinDiskMap.csproj`.
- Документация вынесена в `docs/`; README оставлен кратким.
- Авторские права указаны как Andrei Korneev.

### Известные ограничения

- WinRM-режим реализован, но ещё не проверен на реальном удалённом хосте.
- Подпись архивов включается только после настройки SignPath и одобрения запроса.
