# Интерфейс TUI

TUI включается по умолчанию, если запущено без `--csv` и `--headless`. Дерево появляется
сразу после старта скана и обновляется по мере поступления данных — ждать окончания обхода
не нужно.

## Заголовок и дерево

- В шапке — фаза скана (`MFT`, `Обход каталогов`, ...), счётчики папок/файлов и общий объём.
  Текущие пути в шапку не выводятся: при большой скорости обхода они только мешают.
- Колонки дерева: `Путь / Размер / % / Создан / Посл. запись`. Между ними — по два пробела,
  перед датами отступ шире: колонки разной ширины не слипаются, но экран не загрязнён
  вертикальными линиями.
- Даты показываются в местном времени; источник — `$STANDARD_INFORMATION` с фолбэком
  `$FILE_NAME` в MFT-режиме и `WIN32_FIND_DATA` при обходе. Подробности —
  [MECHANICS.md](MECHANICS.md).
- На узком терминале сначала скрываются даты, затем процент; размер остаётся всегда.
  Окно перерисовывается автоматически при изменении размера консоли.

## Цвета

| Объект | Цвет |
|---|---|
| Папка | голубой |
| Обычный файл | белый |
| `tmp` / `temp` | жёлтый |
| Файлы дампов (`*.dmp`, `*.mdmp`) | пурпурный |

Активная колонка сортировки подсвечена в шапке, стрелка показывает направление.

## Заглушки

| Состояние | Что показывается |
|---|---|
| Скан ещё идёт | `...` (пока данные ещё не поступили) |
| Папка реально пуста | `<Пусто>` (ru) / `<Empty>` (en) |
| Объекты есть, но фильтр их скрывает | `<Отфильтровано>` (ru) / `<Filtered>` (en) |

## Управление

| Клавиша | Действие |
|---|---|
| ↑ ↓, PgUp/PgDn, Home/End | навигация по дереву |
| ← | свернуть папку или перейти к родителю |
| → | развернуть папку или спуститься к первому потомку |
| Enter | папка — переключить свёрнутость; файл — открыть через ассоциацию Windows (`ShellExecute`) |
| `f` | фильтр: папки → папки и файлы → tmp → дампы |
| `s` | сортировка: размер ↓ → размер ↑ → имя ↑ → имя ↓ |
| `e` | экспорт текущего дерева в CSV |
| Del | удалить файл/папку с диска после подтверждения `y/N`; корень скана удалить нельзя |
| колесо мыши | прокрутка |
| левый клик | переместить курсор и раскрыть/свернуть папку (мышь SGR) |
| `q`, Esc | выход |

Диалог удаления — центрированный блок с красной рамкой; безопасный ответ `N` выбран по
умолчанию. Две статусные строки (счётчики/фильтр/сортировка и подсказка клавиш) привязаны
к нижнему краю окна и не перемещаются при раскрытии деревьев или смене фильтра.

## Язык и выход

Язык интерфейса выбирается автоматически: ru при русской локали ОС, иначе en. Переопределить
можно через `--lang ru|en`. CSV при этом остаётся английским в любом случае.

При выходе (в том числе по Ctrl+C) программа сбрасывает ANSI-атрибуты, возвращает курсор,
отключает режим мыши SGR и очищает экран. Код выхода при Ctrl+C — 130. Если реального
терминала нет (например, вывод перенаправлен в файл), TUI не запускается: используйте
`--headless` или `--csv`, код выхода будет 3.
