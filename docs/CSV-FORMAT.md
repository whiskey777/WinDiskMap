# Формат CSV

Единый «комбинированный» формат для локального, агентного и удалённого скана.

## Общие правила

- Кодировка: **UTF-8 с BOM**; разделитель — `,`; перевод строки — `\r\n`.
- Строки-баннера перед заголовком нет. Заголовок — первая строка файла.
- Заголовки и значения всегда английские; `--lang` и локаль ОС на них не влияют.
- Числа пишутся без разделителей разрядов. Дата — локальное время, `yyyy.MM.dd HH:mm:ss`.
- Запись потоковая: строка появляется в файле сразу после агрегации узла, без буферизации
  всего дерева в памяти.

```csv
File name,Size,On disk,Modified,Attributes,Files,Folders,Depth,Parent,Name,Category,SizeHuman,Percent,DRIVECAPACITY,FREESPACE,USEDSPACE,RESERVEDSPACE
```

## Колонки

| № | Колонка | Смысл |
|---|---|---|
| 1 | `File name` | Полный путь с завершающим `\` для папок. Ключ строки. |
| 2 | `Size` | Логический размер файла или сумма размеров всего поддерева. |
| 3 | `On disk` | Реально занятые кластеры: из `$DATA`-runs в MFT-режиме, из `FILE_STANDARD_INFO` при обходе (с поправкой на резидентные файлы). |
| 4 | `Modified` | Время последней записи в локальном времени. Источник — `$STANDARD_INFORMATION`. |
| 5 | `Attributes` | Нормализованные атрибуты Windows. У папок `0x10000000` заменяется на `0x10`, у корня — `0`. |
| 6 | `Files` | Количество файлов в поддереве, включая текущую папку. |
| 7 | `Folders` | Количество папок-потомков **без текущей строки** (`SubtreeDirs - 1`). |
| 8 | `Depth` | Глубина относительно корня скана: `0` у корня. |
| 9 | `Parent` | Полный путь родителя; у корня — пустая строка. |
| 10 | `Name` | Имя объекта. У корня — последний компонент пути (`AI` для `C:\AI\`). |
| 11 | `Category` | `Folder`, `File`, `Temp` или `Dump`. |
| 12 | `SizeHuman` | Размер в удобном виде (`478 GB`, `23.0 KB`). |
| 13 | `Percent` | Доля от размера корня скана (`0.43%`). |
| 14 | `DRIVECAPACITY` | Ёмкость тома — только в строке корня. |
| 15 | `FREESPACE` | Свободно на томе — только в строке корня. |
| 16 | `USEDSPACE` | Занято на томе — только в строке корня. |
| 17 | `RESERVEDSPACE` | Зарезервировано — только в строке корня. |

Значения колонок 14–17 в остальных строках пустые. `FREESPACE`/`USEDSPACE` отражают состояние
тома **на момент скана**, поэтому два репорта, сделанные в разное время, отличаются только
этими числами.

## Режимы отбора

| Опция | Что попадает в CSV |
|---|---|
| `--only dirs` (по умолчанию) | Только строки папок: агрегаты поддеревьев |
| `--only dirs --details` | Папки **и** строка на каждый файл |
| `--only files` | Только файлы (все категории файлов) |
| `--only tmp` | Только файлы с `tmp`/`temp` в имени |
| `--only dumps` | Только файлы дампов (`*.dmp`, `*.mdmp`) |

`--depth N` ограничивает глубину строк: `0` — только корень, `1` — корень и его непосредственные
потомки. Файл внутри папки уровня N имеет глубину N+1 и при `--depth N` не пишется.

## Пример разбора

```powershell
# Импорт без параметров: BOM и разделитель определяются автоматически
$r = Import-Csv C:\tmp\report.csv

# Крупнейшие папки первого уровня
$r | Where-Object { $_.Depth -eq '1' -and $_.Category -eq 'Folder' } |
     Sort-Object { [int64]$_.Size } -Descending |
     Select-Object -First 10 'File name', SizeHuman, Files, Folders

# Только дампы, больше 1 ГБ
$r | Where-Object { $_.Category -eq 'Dump' -and [int64]$_.Size -gt 1GB }
```

## Особенности подсчёта

- Hardlink учитывается в каждом каталоге-владельце: один файл с несколькими `$FILE_NAME`
  увеличивает `Size` нескольких папок. Сумма по дереву — не «уникальные байты тома».
- Reparse-папки (junction/symlink) присутствуют в CSV с нулевым размером и не обходятся.
- `$MFT` входит в размер корня тома: это реально занятый файл, невидимый обычным обходом.
- Для резидентных файлов `On disk` равен 0, даже если Windows показывает секторный
  `AllocationSize` (например, 288 байт для файла в 287 байт).
- Порядок строк определяется обходом дерева и может отличаться между MFT- и обходным
  режимом. Сравнивать репорты нужно по колонке `File name`, а не построчно.
