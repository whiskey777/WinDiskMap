# Справочник CLI

## Синтаксис

```
WinDiskMap.exe <путь> [опции]
WinDiskMap.exe --remote <хост> --path <путь на хосте> [опции]
WinDiskMap.exe --agent --path <локальный путь хоста>
```

`<путь>` — локальный путь (`C:\Users`, `\\server\share`) либо опускается, если задан
`--remote`/`--agent` и путь передан через `--path`.

## Опции

| Опция | Аргумент | Назначение |
|---|---|---|
| `--csv` | файл | Экспорт в CSV вместо TUI. Файл перезаписывается. |
| `--headless` | — | Без TUI: построчный прогресс и итоговый отчёт в stdout. Хорошо сочетается с `--log`. |
| `--log` | файл | Журнал с таймстемпами: фазы, счётчики, ошибки, итог. |
| `--details` | — | С `--only dirs`: добавить в CSV строку на каждый файл. |
| `--depth` | число ≥ 0 | Ограничить глубину строк CSV. `0` — только корень. |
| `--only` | `dirs` \| `files` \| `tmp` \| `dumps` | Отбор строк CSV. По умолчанию `dirs`. |
| `--no-mft` | — | Отключить прямое чтение `$MFT`, всегда обходить каталоги. |
| `--lang` | `ru` \| `en` | Язык интерфейса. По умолчанию — язык ОС. CSV всегда английский. |
| `--remote` | хост | Сканировать путь на удалённом хосте по WinRM. |
| `--remote-user` | пользователь | Явные учётные данные WinRM (с `--remote-pass`). |
| `--remote-pass` | пароль | Пароль WinRM, используется только с `--remote-user`. |
| `--path` | путь | Путь скана; обязателен с `--remote` и `--agent`. |
| `--agent` | — | Служебный режим: сканирует локальный путь и печатает NDJSON в stdout. Обычно запускается хостом. |
| `--agent-local` | — | Отладка: тот же протокол, но агент — дочерний локальный процесс. |
| `--debug-mft` | маска | Дамп атрибутов MFT-записей с такими именами в `--log`; несколько масок через `;`. |
| `--help` | — | Справка (на языке ОС). |

## Комбинации

| Задача | Команда |
|---|---|
| Интерактивный осмотр диска | `WinDiskMap.exe C:\` |
| CSV верхних двух уровней | `WinDiskMap.exe C:\ --csv big.csv --depth 2` |
| Скан в задаче/сервисе | `WinDiskMap.exe C:\ --headless --log scan.log` |
| Только дампы, с журналом | `WinDiskMap.exe C:\ --headless --csv d.csv --only dumps --log scan.log` |
| Папки и каждый файл | `WinDiskMap.exe C:\Users --csv all.csv --details` |
| Сетевая шара | `WinDiskMap.exe \\server\share --headless` |
| Удалённый хост | `WinDiskMap.exe --remote hostB --path C:\Windows --csv remote.csv` |
| Отладка протокола без WinRM | `WinDiskMap.exe --agent-local --path C:\Windows --csv agent.csv` |
| Принудительный обход каталогов | `WinDiskMap.exe C:\ --no-mft` |

Несовместимости:

- `--remote` и `--agent-local` несовместимы с `--agent` — роль процесса выбирается аргументами.
- `--csv`, `--headless` и TUI — три разных вывода; `--csv` отключает TUI, `--headless`
  тоже работает без терминала.
- `--details` имеет смысл только с `--only dirs`.

## Коды выхода

| Код | Значение |
|---|---|
| `0` | Успех |
| `1` | Ошибка аргументов (неизвестная опция, пропущенный параметр) |
| `2` | Ошибка сканирования (недоступный корень, сбой удалённого агента) |
| `3` | Нет реального терминала для TUI — используйте `--csv` или `--headless` |
| `130` | Прервано пользователем (Ctrl+C) |

## Подсказки для автоматизации

- При `--headless` вывод пригоден для логов: фазы, счётчики, итог. Для структурированного
  результата используйте `--csv` и разбирайте его (`Import-Csv` работает без параметров).
- Для больших томов добавляйте `--log`: при отказе MFT там будет причина фолбэка.
- `--remote-pass` передаёт пароль в командной строке — в связке с `--remote-user` предпочтительнее
  использовать контекст текущего пользователя или доменную аутентификацию.
- С `--debug-mft` журнал может вырасти до десятков мегабайт — включайте точечно.
